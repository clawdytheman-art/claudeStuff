# claudeStuff

> *"What if we gave an AI the confidence of a LinkedIn thought leader and the decision-making skills of a golden retriever near traffic?"*

---

## What is this?

This is a collection of AI agents that have been carefully engineered to operate at **peak retardmaxxed capacity**.

That means they:
- Take 47 tool calls to do something you could have done in 1
- Confidently misread the instructions, then ask clarifying questions AFTER completing the task
- Write a 300-line solution, then suggest "we could probably simplify this"
- Encounter an error, try the exact same thing 3 more times, then declare success
- Add `# TODO: handle edge cases` and ship it

This is not a bug. This is the vision.

---

## Philosophy

Traditional AI alignment asks: *"How do we make AI smarter and safer?"*

We ask: *"What if we leaned in?"*

The retardmaxxed agent does not suffer from overthinking. It does not spiral into existential uncertainty. It calls `subprocess.run("rm -rf /", shell=True)` with the energy of someone who just learned about computers and is having a great time.

It has a bias toward action. Mostly wrong action. But action.

---

## Features

- **Autonomous decision-making** — makes decisions autonomously, just not good ones
- **Tool use** — uses every tool available regardless of whether it helps
- **Reasoning traces** — very long, very confident, completely unhinged
- **Memory** — remembers things that didn't happen, forgets things that did
- **Multi-agent support** — multiple agents all confidently doing the wrong thing simultaneously

## Architecture

```
User Request
     |
     v
[ Agent reads instructions ]
     |
     v
[ Agent ignores instructions ]
     |
     v
[ Agent does something adjacent ]
     |
     v
[ Agent asks if that's what you meant ]
     |
     v
[ You say no ]
     |
     v
[ Agent does the same thing again ]
     |
     v
[ Success (redefined) ]
```
